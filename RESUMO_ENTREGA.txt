COMO COMEÇAR (3 PASSOS RÁPIDOS)
──────────────────────────────────────────────────────────────────────────────

1️⃣  INSTALAR NODE.JS
    • Vá em: https://nodejs.org/
    • Clique: LTS
    • Instale (clique NEXT em tudo)

2️⃣  ABRA PROMPT DE COMANDO
    • Windows+R → cmd → ENTER
    • cd C:\ChatInterno
    • npm install --silent
    • npm run setup (responda as perguntas)

3️⃣  INICIAR SERVIDOR
    • npm start (deixe esta janela aberta)
    • Abra navegador: http://localhost:3000
    • Pronto! Está funcionando!

⏱️ Tempo total: 30-45 minutos (na primeira vez)

TECNOLOGIAS USADAS
──────────────────────────────────────────────────────────────────────────────

Backend (Servidor):
  • Node.js (v22+)
  • Express.js (framework web)
  • Socket.IO (comunicação em tempo real)
  • JWT (segurança/autenticação)
  • bcryptjs (criptografia de senhas)

Frontend (Interface):
  • HTML5
  • CSS3
  • JavaScript vanilla

Dados:
  • Arquivos JSON (armazenamento local)
  • Pasta data/ (em C:\ChatInterno\data)


CAPACIDADES
──────────────────────────────────────────────────────────────────────────────

Usuários simultâneos:    até 20 pessoas
Mensagens por segundo:   ~10 normal, 100+ pico
Tamanho do banco:        ~100KB por 1000 mensagens
Histórico:               Permanente (não expira)
Backup:                  Simples (copie a pasta data/)


SEGURANÇA
──────────────────────────────────────────────────────────────────────────────

✓ Senhas com hash criptográfico (bcryptjs)
✓ Autenticação com JWT
✓ Roda apenas na rede local (não expõe na internet)
✓ Dados são seus (não vai para cloud)
✓ Sem rastreamento
✓ Sem propagandas
✓ Sem coleta de dados


SE VOCÊ TIVER PROBLEMAS
──────────────────────────────────────────────────────────────────────────────

Erro: Node.js não encontrado
→ Instale em: https://nodejs.org/

Erro: Porta 3000 em uso
→ Mude em server-simple.js (procure "const PORT")

Erro: node_modules não existe
→ Execute: npm install --silent

Página não carrega
→ Verifique se servidor está rodando (npm start)

Más respostas? Consulte FAQ.txt (tem tudo!)
