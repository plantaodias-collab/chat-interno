✓ PASSO 1: INSTALAR NODE.JS (5 MINUTOS)
──────────────────────────────────────────────────────────────────────────────

O que é Node.js?
  É um programa que faz o chat funcionar. Precisa instalar uma única vez.

Como fazer:

1. Abra seu navegador (Chrome, Firefox, Edge, Safari... qualquer um)

2. Na barra de endereço (onde você digita www.google.com), clique

3. Apague tudo que está lá e digite:
   https://nodejs.org

4. Pressione ENTER

5. Vai abrir a página da Node.js com 2 botões grandes:

   Você vai ver:
   ┌────────────────────────────────────────────┐
   │  nodejs.org/                               │
   │                                            │
   │    [LTS]              [Current]           │
   │    ↑ CLIQUE AQUI     (ignore este)        │
   │                                            │
   └────────────────────────────────────────────┘

6. Clique no botão LTS (à esquerda)

7. Vai começar a baixar um arquivo

8. Procure este arquivo (geralmente em Downloads):
   "node-v22.22.0-x64.msi"

9. Clique 2x neste arquivo (duplo clique)

10. Vai abrir um programa de instalação. Você vai ver várias telas:

    Tela 1: "Welcome to Node.js"
    → Clique: NEXT

    Tela 2: "License Agreement"
    → Clique: NEXT (ou marque "I Accept" antes)

    Tela 3: "Destination Folder"
    → Clique: NEXT (deixe como está)

    Tela 4: "Custom Setup"
    → Clique: NEXT (deixe como está)

    Tela 5: "Ready to Install"
    → Clique: INSTALL

    Tela 6: (aguarde a instalação)

    Tela 7: "Completed"
    → Clique: FINISH

11. Pronto! Node.js foi instalado! ✓

Para verificar se funcionou:

1. Pressione as teclas: Windows + R
   (a tecla Windows é aquela com a logo do Windows)

2. Aparecerá uma caixa com um campo de texto

3. Digite:     cmd

4. Pressione: ENTER

5. Aparecerá uma janela preta (Prompt de Comando)
   Você verá algo como:
   C:\Users\SeuNome\>

6. Digite:     node --version

7. Pressione: ENTER

8. Deve aparecer um número como:
   v22.22.0

Se apareceu um número = SUCESSO! ✓

Se não apareceu = Node.js não foi instalado. Tente novamente.


✓ PASSO 2: PREPARAR OS ARQUIVOS (5 MINUTOS)
──────────────────────────────────────────────────────────────────────────────

Você já tem todos os arquivos do Chat Interno.

Agora precisa organizá-los em uma pasta.

Como fazer:

1. Abra o Windows Explorer
   (aquele ícone de pasta na barra de tarefas)

2. Vá para a raiz do C:
   Na barra de endereço (onde mostra o caminho), clique
   Apague tudo
   Digite: C:\
   Pressione ENTER

3. Você está em C:\ agora

4. Procure por espaço vazio na pasta
   (não clique em nenhum arquivo/pasta)

5. Clique com o BOTÃO DIREITO do mouse em espaço vazio

6. Aparecerá um menu com opções:
   ┌──────────────────────────┐
   │ Novo                 →   │
   │ Colar                    │
   │ Atualizar                │
   │ Propriedades             │
   └──────────────────────────┘

7. Passe o mouse por "Novo" (à direita aparecerá um submenu)

8. Clique em: "Pasta"

9. Aparecerá uma pasta nova com o nome selecionado
   "Nova Pasta"

10. O nome já está selecionado (azul). Apague e digite:
    ChatInterno

11. Pressione: ENTER

12. Pronto! Agora você tem a pasta C:\ChatInterno

Agora copie os arquivos:

1. Procure por todos os arquivos que você baixou
   (devem estar em Downloads ou em alguma pasta)

2. Os arquivos são:
   ✓ server-simple.js
   ✓ index.html
   ✓ package-simple.json
   ✓ setup-simple.js
   ✓ GUIA_PARA_LEIGOS.txt
   ✓ E mais alguns arquivos .txt

3. Selecione TODOS os arquivos:
   Pressione: Ctrl + A
   (tudo fica azul = selecionado)

4. Copie:
   Pressione: Ctrl + C

5. Agora abra a pasta C:\ChatInterno que você criou

6. Cole os arquivos:
   Pressione: Ctrl + V

7. Pronto! Todos os arquivos estão em C:\ChatInterno ✓

Como fazer:

1. Pressione: Windows + R

2. Aparece a caixa de texto

3. Digite: cmd
