O QUE VOCÊ RECEBEU
──────────────────────────────────────────────────────────────────────────────

Aplicativo completo de comunicação em tempo real para sua equipe.

Funcionalidades Principais:
  ✓ Chat em grupos
  ✓ Mensagens privadas
  ✓ Notificações automáticas
  ✓ Painel de administração
  ✓ Gerenciamento de usuários
  ✓ Histórico de mensagens
  ✓ Funciona em rede local
  ✓ Acessa de computador ou celular


ANTES DE INICIAR
──────────────────────────────────────────────────────────────────────────────

Você precisa de:
  1. Node.js instalado (baixar em https://nodejs.org)
  2. Windows, Mac ou Linux
  3. Rede local disponível (WiFi ou cabo)


3 PASSOS PARA COMEÇAR
──────────────────────────────────────────────────────────────────────────────

PASSO 1 - INSTALAR (5 minutos)
───────────────────────────────
  Windows:
    1. Abra a pasta dos arquivos
    2. Clique 2x em "configurar.bat"
    3. Responda as perguntas
    4. Aguarde até dizer "Configuração concluída"

  Mac/Linux:
    1. Abra terminal
    2. Va até a pasta
    3. Execute: npm run setup
    4. Responda as perguntas


PASSO 2 - INICIAR SERVIDOR (1 minuto)
───────────────────────────────────────
  Windows:
    1. Clique 2x em "iniciar.bat"
    2. Janela abrirá
    3. Vejo: "Servidor rodando..."

  Mac/Linux:
    1. No terminal, execute: npm start


PASSO 3 - USAR (Imediato)
──────────────────────────
  1. Abra navegador
  2. Acesse: http://localhost:3000
  3. Faça login com seus dados criados no PASSO 1
  4. Está pronto para usar!


FUNCIONÁRIOS: COMO ACESSAR
──────────────────────────────────────────────────────────────────────────────

Você (admin) criará usuários com:
  • Email deles
  • Senha padrão: Senha123!

Eles acessam em:
  http://localhost:3000  (mesma máquina)
  http://SEU_IP:3000     (outra máquina)

Exemplo real:
  Admin criou: joao@empresa.com (senha: Senha123!)
  João acessa: http://192.168.1.100:3000
  Login: joao@empresa.com / Senha123!
  Pronto!

ADMIN: SUAS RESPONSABILIDADES
──────────────────────────────────────────────────────────────────────────────

1. INICIAR O SERVIDOR
   □ Diariamente (ou 24h conforme necessário)
   □ Clique em "iniciar.bat"

2. CADASTRAR USUÁRIOS
   □ Painel Admin > "Cadastrar Novo Usuário"
   □ Compartilhe email + "Senha123!" com o funcionário

3. CRIAR GRUPOS
   □ Painel Admin > "Criar Novo Grupo"
   □ Todos usuários terão acesso automático

4. FAZER BACKUP
   □ Copie "chat.db" periodicamente
   □ Guarde em local seguro

5. SUPORTE
   □ Responda dúvidas dos usuários
   □ Consulte FAQ.txt para problemas


USUÁRIO FINAL: COMO USAR
──────────────────────────────────────────────────────────────────────────────

1. LOGIN
   □ Acesse http://IP:3000
   □ Digite email e senha recebidos
   □ Clique "Entrar"

2. ENVIAR MENSAGEM EM GRUPO
   □ Clique nome do grupo (barra esquerda)
   □ Digite mensagem
   □ Pressione ENTER

3. ENVIAR PRIVADO
   □ Clique nome da pessoa (Contatos)
   □ Digite mensagem
   □ Pressione ENTER

4. RECEBER NOTIFICAÇÕES
   □ Notificação aparece topo direito
   □ Clique para ir ao chat
   □ (Opcional) Permita notificação do navegador


PERGUNTAS COMUNS
──────────────────────────────────────────────────────────────────────────────

P: Preciso de internet?
R: Não. Funciona totalmente em rede local.

P: Funciona no celular?
R: Sim, em qualquer navegador do celular.

P: Onde os dados ficam armazenados?
R: No arquivo "chat.db" da máquina servidor.

P: Posso alternar de máquina?
R: Sim, sempre que acesse http://IP:3000

P: Como faço backup?
R: Copie o arquivo "chat.db" para local seguro.

P: Esqueci a senha!
R: Admin vai te criar novo usuário.

P: Posso rodara 24h?
R: Sim, deixe servidor sempre ligado se necessário.


SEGURANÇA BÁSICA
──────────────────────────────────────────────────────────────────────────────

✓ Senhas criptografadas (não são salvas em texto limpo)
✓ Autenticação em cada acesso (JWT Token)
✓ Rede local = mais segura

⚠ Não recomendado expor na internet pública
⚠ Se expor, adicionar HTTPS e firewall


PERFORMANCE
──────────────────────────────────────────────────────────────────────────────

Até 20 pessoas: ótimo desempenho
20-50 pessoas: funciona com possíveis lentidões
50+: precisa otimizações
