TRÊS PASSOS SUPER RÁPIDOS
──────────────────────────────────────────────────────────────────────────────

1. Instale Node.js: https://nodejs.org/ (clique em LTS)

2. Abra Prompt de Comando (Windows+R, cmd, ENTER)
   Digite: cd C:\ChatInterno
   Digite: npm install --silent
   Digite: npm run setup
   Responda as 4 perguntas

3. Na mesma janela:
   Digite: npm start
   Abra navegador em: http://localhost:3000

COMEÇAR: PASSO 4
──────────────────────────────────────────────────────────────────────────────

Configurar seu acesso de administrador

1. Na mesma janela:
   ✓ Digite: npm run setup
   ✓ Pressione: ENTER

2. Responda as 4 perguntas:

   PERGUNTA 1: "Nome do administrador:"
   Responda: Seu nome completo (ex: João Silva)
   Pressione: ENTER

   PERGUNTA 2: "E-mail do administrador:"
   Responda: Seu email (ex: joao@empresa.com)
   Pressione: ENTER

   PERGUNTA 3: "Senha do administrador:"
   Responda: Uma senha forte (ex: Minha@Senha123)
   Pressione: ENTER

   PERGUNTA 4: "Deseja criar grupos de exemplo? (s/n):"
   Responda: s
   Pressione: ENTER

3. Verá a mensagem:
   "Configuração finalizada com sucesso!"

ANOTE AGORA:
   Email: _________________ (o que você digitou)
   Senha: _________________ (a que você criou)

Você vai usar isto para fazer login!

Se conseguiu = sucesso! Vá para PASSO 5
